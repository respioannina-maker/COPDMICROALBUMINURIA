# CRF ΧΑΠ – Στατική βιτρίνα (GitHub Pages) με CSV Export

Αυτή είναι μια απλή, όμορφη φόρμα CRF (στα ελληνικά) για κινητό/PC.
Δεν χρειάζεται Google/Airtable. Τα δεδομένα αποθηκεύονται προσωρινά στον browser
και μπορείτε να τα **εξάγετε σε CSV** (Excel) με ένα κλικ.

## Χρήση
1. Ανεβάστε αυτά τα αρχεία σε ένα public GitHub repo (π.χ. crf-copd).
2. Ενεργοποιήστε GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).
3. Ανοίξτε το link (π.χ. https://<username>.github.io/crf-copd).
4. Συμπληρώστε τη φόρμα (NPS + Ενότητα + πεδία). Πατήστε **Αποθήκευση τοπικά**.
5. Όταν θέλετε, πατήστε **Εξαγωγή CSV** για να κατεβάσετε όλα τα δεδομένα σε ένα αρχείο.
6. Το CSV ανοίγει σε Excel. Μπορείτε να το ανεβάσετε πίσω στο repo για κοινή χρήση.

> Σημείωση: Ως "στατική" σελίδα, δεν μπορεί να γράψει αυτόματα σε server/Google/Airtable
χωρίς backend. Γι’ αυτό αποθηκεύει τοπικά και κάνει export CSV.

## Παραμετροποίηση
- Προσθέστε/αφαιρέστε πεδία απευθείας στο `index.html` (labels και inputs).
- Το look ρυθμίζεται από `styles.css`.
- Η λογική αποθήκευσης/εξαγωγής είναι στο `app.js`.
